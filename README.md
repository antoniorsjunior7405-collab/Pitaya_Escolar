# Pitaya_Escolar
Aplicativo de transporte escolar desenvolvido com React Native, Expo e TypeScript. O Pitaya Escolar conecta motoristas e responsáveis, permitindo acompanhar rotas, registrar embarques e desembarques e consultas de status dos alunos. O projeto utiliza Supabase e PostgreSQL como base, armazenamento e sincronização segura dos dados.
