# Pitaya Escolar

Aplicativo de transporte escolar que conecta motoristas e responsáveis: rotas, embarque/entrega de alunos, localização em tempo real e notificações.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `frontend/` | App mobile em React Native + Expo + TypeScript |
| `backend/` | API / servidor em Node.js |
| `docs/` | Documentação (ver [boas práticas](docs/BOAS_PRATICAS.md)) |

## Frontend

```bash
cd frontend
npm install
npx expo start
```
